# 路线图

## v1.0.0 发布候选状态

v1.0.0 的五个优先级范围已冻结，代码、自动自检、文档和 Windows x64 发布包已完成。当前标签为 `v1.0.0-rc.1`，原因是本环境没有真实 Xbox / DualSense 设备，无法诚实地把输入、震动、触摸和体感标记为 `Supported and verified`。

路线图描述计划，不代表已经交付。每项完成必须同时满足代码、自检和适用的真实设备验证。

## 阶段 1：摇杆专业检测

- **目标：** 提高静止漂移、范围、稳定性和建议死区的实机可信度。
- **依赖：** 统一 `ControllerState`，真实 Xbox / DualSense 输入样本。
- **完成标准：** 连续检测、异常触碰判定、范围检查和中文报告在两类设备上有记录。
- **风险：** 不同驱动的归一化范围和震动干扰采样。
- **当前状态：** 代码实现完成：连续检测、触碰无效判定、范围检查、中文报告和本地可追溯记录均已具备；仍缺 Xbox 与 DualSense 的真实设备记录，因此不得标为实机验证完成。

## 阶段 2：一键手柄健康检测与报告

- **目标：** 汇总按键、摇杆、扳机和连接状态，形成清楚的本地检测结果。
- **依赖：** 阶段 1 的阈值和真实设备回归。
- **完成标准：** 报告只来自真实输入，明确未通过项和不确定项，可在界面查看 / 复制。
- **风险：** 将演示、构造数据或短暂断连错误写入正式报告。
- **当前状态：** 部分完成；已有按键、摇杆和扳机报告模型，尚需产品化验收。

## 阶段 3：震动系统专业化

- **目标：** 可靠支持左右通道、预设模式和完整安全停止链路。
- **依赖：** XInput 与 DualSense USB / 蓝牙实机输出验证。
- **完成标准：** 停止、页面离开、设备切换、断开和应用退出均可复现地停止震动；实机通道不反转。
- **风险：** HID 输出报告差异、第三方 XInput 兼容性与残留异步任务。
- **当前状态：** 初始实现完成，DualSense 两种输出模式均待实机验证。

## 阶段 4：DualSense 触摸板与体感高级检测

- **目标：** 在支持完整 HID 报告时稳定展示最多两触点、姿态和校准质量。
- **依赖：** USB / 蓝牙完整报告、CRC 验证与静止环境。
- **完成标准：** 触点方向、ID 追踪、姿态重心、断连恢复和数据可用性提示均经真实手柄验证。
- **风险：** 蓝牙紧凑兼容报告没有触摸 / 运动字段，Yaw 缺少绝对航向参考。
- **当前状态：** 部分完成；解析与视觉组件已存在，待实机验证。

## 阶段 5：UI 与产品化收尾

- **目标：** 保持当前中央手柄视觉语言，完善说明、错误提示、版本化和可复现发布流程。
- **依赖：** 前述能力的真实验证结论与 Overlay 稳定资产。
- **完成标准：** 文档、版本、截图、回归清单和发布包一致；不破坏已校准 Overlay。
- **风险：** 为视觉微调引入坐标回归，或在未验证状态下过度承诺硬件能力。
- **当前状态：** 发布候选完成；低风险 UI、状态文案、隐私提示、版本管理、CHANGELOG、许可证和发布结构已收尾。后续只处理实机验证和阻塞问题。
