## 三条工程红线（改版期间不得破坏）

1. **安全**：震动默认 ≤40% / ≤5s、单次 ≤30s；离开页面、断开、切换、退出必须停止归零；与静止采样互斥。
2. **真实性**：只接受真实输入；未实机验证的能力保持标注；示例数值不得进入正式报告。
3. **资产**：已校准 Overlay 坐标与真实 PNG 遮罩不得修改或从概念图反向提取。

## 施工顺序（省额度版）

1. 补状态规格（已完成 → 见上方规格文档）
2. **结构拆分**：`ControllerLab.cs` → 单文件 ≤ 2,000 行（机械活，低成本模型可做）
3. 按页视觉改版（一页一提交）
4. 实机验证
