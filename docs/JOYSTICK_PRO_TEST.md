# 摇杆专业检测模块

## 代码边界

- `JoystickAnalyzer.cs`：数据模型、集中阈值、静止/圆周/回中/死区/健康评分算法与构造自检。
- `JoystickTestViewModel.cs`：真实输入采样、倒计时、测试状态机、`CancellationToken`、断开/切换取消。
- `JoystickTestPage.cs`：原生 WPF 页面、操作控件、详细结果与轨迹绘制；不包含诊断算法。
- 输入继续来自 `ControllerState`。它由既有 XInput 或 DualSense HID 适配器生成；专业检测读取应用显示校准前的 `-1.0～1.0` 值，不再次施加死区。

## 圆周覆盖率

完整圆周固定切为 72 个 5° 区间。每个区间只保留该方向观测到的最大半径；半径达到 80% 的区间记为外圈覆盖。外圈覆盖率为达标区间数除以 72，因此同一路径重复采样不会抬高覆盖率，结果不依赖采样点总数。四象限覆盖取四个象限中最低的区间覆盖率，避免三个象限的密集数据掩盖缺失象限。

圆度误差以 72 个方向最大半径相对中位半径的均方根误差为主体，并对超过单位圆的对角半径增加惩罚。方形限制由对角方向半径显著大于轴向半径识别；明显削角由对角方向半径显著小于轴向半径识别。

## 自动死区

噪声余量综合 X/Y 较大的标准差、二维噪声，并保留至少 0.5% 的测量余量。最低死区不低于“静止最大偏移 + 噪声余量”；推荐死区再增加动态安全余量；稳定死区进一步增加抗抖余量。三档均以 0.5% 向上取整，并限制在 1%～30%。圆形建议使用推荐档；轴向建议按 X/Y 平均偏移和各轴标准差分别计算。推荐值达到 15% 或静止最大偏移达到 12% 时提示仅增加死区不能彻底解决。

## 健康评分

只有同一摇杆已完成有效静止、圆周及上/下/左/右四方向回中测试时才生成 0～100 分，否则为 `Not Tested / 未检测`。

| 项目 | 权重 |
| --- | ---: |
| 中心稳定性 | 15% |
| 噪声 | 10% |
| 圆周覆盖率 | 15% |
| 圆度 | 10% |
| 四方向行程一致性 | 10% |
| 回中速度 | 15% |
| 反弹/过冲/持续抖动 | 10% |
| 推荐死区大小 | 15% |

状态阈值：90～100 `Excellent / 优秀`，75～89 `Good / 良好`，50～74 `Warning / 需要注意`，0～49 `Critical / 严重异常`。

## 验证边界

`--joystick-analyzer-selftest` 覆盖居中、右漂、随机噪声、完整圆、缺失象限、方形限制、回中过冲、多次反弹、死区下限和空样本十项。该自检验证算法与状态逻辑，不等同于真实 Xbox 或 DualSense 的机械、驱动和采样验证；真实手柄结果仍需分别记录。
